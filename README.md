# 💰 Expense Tracker

A modern MERN Stack Expense Tracker designed to help users manage their finances efficiently. Track income, expenses, budgets, and financial insights through a clean and intuitive dashboard.

---

## 🚀 Features

* User Authentication & Authorization
* Income & Expense Management
* Budget Planning
* Financial Analytics & Insights
* Responsive Dashboard
* Group Expense Management
* Edit & Delete Transactions
* Real-Time Data Updates
* Secure Backend API

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Muzafar-Tech/expense-tracker.git
```

### Install Dependencies

Client

```bash
cd client
npm install
```

Server

```bash
cd server
npm install
```

### Environment Variables

Create a `.env` file inside the server directory and add:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```

### Run Application

Server

```bash
npm run server
```

Client

```bash
npm start
```
